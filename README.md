# Chai IT Help Desk

Chai is a rule-based IT support chatbot and ticketing portal built as a practical IT support portfolio project.

## Live demo

[Open Chai IT Help Desk](https://northstar-it-help-desk.anithbhaskar.chatgpt.site)

## What it demonstrates

- Guided troubleshooting for common employee IT problems
- Wi-Fi, accounts, printers, hardware, software and email support
- VPN, shared-drive, file-storage, backup and mobile-device support
- Immediate escalation for ransomware, clicked phishing links, stolen devices and suspicious logins
- Ticket creation with priority levels
- Technician dashboard with Open, In progress and Resolved states
- Clear, employee-safe instructions that avoid risky administrator actions

## How it works

An employee selects a problem category and describes the issue. Chai then follows a decision tree, presents safe checks and asks whether the problem is resolved. Problems that need permissions or specialist investigation are escalated to IT. Security incidents bypass normal troubleshooting immediately.
